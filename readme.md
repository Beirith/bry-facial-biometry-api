# Desafio prático Bry - API de Biometria Facial

## Sobre o projeto
Implementação do desafio prático para a vaga de desenvolvedor Java, na empresa Bry Tecnologia.

O projeto está dividido em duas grandes partes:

*Backend* (bry-facial-biometry/backend): desenvolvido em Java juntamente com o framework Spring Boot
para a realização das operações de CRUD de usuários, biometria facial (verificação e identificação) e persistência de
dados no PostgreSQL.

*Frontend* (bry-facial-biometry/frontend): desenvolvido em Angular para consumo da API e interação com o usuário.
